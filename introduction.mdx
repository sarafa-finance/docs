title: "Sarafa Business API"

The Sarafa Business API gives your server access to your verified organization's account. Use it to read balances and transactions, collect payments, send payouts, swap wallet balances, and create hosted checkout links.

## Get started

1. Complete your organization's verification in the merchant dashboard.
2. Create an API key in the dashboard's API section. Save the full key when it is created; the secret is shown only once.
3. Make your first authenticated request:

```bash
curl "https://api.sarafa.site/v3/" \
  -H "Authorization: Bearer $SARAFA_API_KEY" \
  -H "Content-Type: application/json"
```

Keep your API key on your server. It grants access only to your organization's account.

## Choose an operation

| Task | Endpoint | Guide |
| --- | --- | --- |
| Read your organization and account | `GET /v3/` | [Profile](/api-reference/endpoint/profile) |
| Read wallet balances and deposit addresses | `GET /v3/wallets` and `GET /v3/wallets/{currency}` | [Wallets](/api-reference/endpoint/wallet) |
| Read transaction history | `GET /v3/transactions` | [Transactions](/api-reference/endpoint/getTransactions) |
| Check payment status | `GET /v3/transactions/{id}` | [Payment details](/api-reference/endpoint/getTransaction) |
| Collect a payment | `POST /v3/charge` | [Charge](/api-reference/endpoint/charge) |
| Send a payment | `POST /v3/transfer` | [Transfer](/api-reference/endpoint/transfer) |
| Convert wallet balances | `POST /v3/swap` | [Swap](/api-reference/endpoint/exchange) |
| Create or check a hosted payment link | `POST /v3/checkout` and `GET /v3/checkout/{reference}` | [Hosted checkout](/services/checkout) |

Read [authentication and request conventions](/api-reference/introduction) before integrating, then implement [signed callbacks and retries](/services/api).

<Note>
  Charge, transfer, and swap default to a quote. Set `quote` to `false` to execute.
  A response with `status: "success"` confirms the API request succeeded. Only
  `transaction.status: "completed"` confirms payment.
</Note>
